<div class="difficulty beginner-version"  aria-label="Beginner introduction to Microsoft Word Editor spelling and grammar tool">

  <section class="section-light">
  <p>Word features automated tools to review all the content in your document. While you should always read through a document you’ve written, these tools provide a quality standard checker of the spelling and grammar in your document before you publish and distribute it.</p>
  <p>In Word 365 and newer Word versions the <strong >Review</strong> tab on the ribbon has two reviewing tools: <strong>Editor</strong> and <strong>Spelling and Grammar</strong>.</p>
  <p><img class="thumbnail border" src="{{ '/assets/images/word/Spelling and Grammar Editor/Spelling and grammar editor on ribbon.png' | url }}" alt="Spelling and Grammar ad Editor tools on ribbon in Word" style="max-width:512px; width:100%; height:auto; vertical-align:middle"></p>
  <h4>But what is the difference between <em>Editor</em> & the <em>Spelling and Grammar</em> tools?</h4>
  <p>Here’s a quick overview:</p>
  <ul>
  <li><strong>Editor</strong> is the modern reviewing tool introduced in newer versions of Word. It reviews a document’s spelling, grammar, style, clarity and formality and is AI-assisted.</li>
  <li><strong>Spelling and Grammar</strong> is a legacy label from older versions of Microsoft Office that still lives in the ribbon. It gives you a slightly narrower scope: spelling only, or, spelling and grammar but without as much clarity and extras as Editor provides.</li>
  <li>However, <em>Spelling and Grammar</em> runs on the same engine as Editor. It’s essentially the same feature with an old front door left unlocked.</li>
  </ul>
  <h4>So what’s the point of having <em>Spelling and Grammar</em>?</h4>
  <p><u>The answer is if you’re offline</u>. Editor requires an internet connection to work because of its AI component. Spelling and Grammar is left in to give you an automated reviewing tool if you’re without an internet connection.</p>
  <p>So in conclusion: <strong>Use <em>Editor</em>, unless you’re offline in which case use <em>Spelling and Grammar</em></strong>.</p>
  <p>For this article we’re going focus on <em>Editor</em>. If you have an older version of Word then you won’t have this feature but <em>Spelling and Grammar</em> follows the same processes enough for you to be able to pick it up.</p>
  <h2>How to use Editor</h2>
  <p>Clicking on <strong>Editor</strong> will bring up a pane on the edge of the app screen. There are several categories of what it reviews. Click on the red dots to learn what each does.</p>

    <h2>Limitations – What it can’t do</h2>
      <p>You can't rely on a spell checker to do all the work for you. Editor is good at picking up on spelling errors and most grammatical slip ups but it isn't going to pick up everything. It can't really detect an issue with something that requires context to understand or fix.</p>
      <p>Personally I always re-read what I've written to make sure it makes sense. Always read through a document yourself before you call it finished.</p>
      <p>Some examples of Editor's limitations are listed in the <a href="?difficulty=intermediate">intermediate version</a> of this article.</p>

  <section class="section-light">
    <h2>Limitations – What it can’t do</h2>
      <p>At the end of the day you should read and proofread your own work. I come from an Editor background so I’ll always advocate for that. At the end of the day it’s a computer program, not a human, and there’s a limit to what it can understand and do.</p> 
      <p>Here’s some examples of where the checker can miss or confuse something and what you need to look out for checking content yourself:</p>
      <h4>Missing words</h4>
      <p><u>Example</u>: ‘<em>She went store</em>.’</p>
      <p><u>Problem</u>: Missing ‘to the’ before ‘store’. Editor is usually good at detecting missing words but drop a word in a longer sentence and it can get missed more often.</p>
      <h4>Numbers, dates, and units that are valid but wrong</h4>
      <p>Tense or number agreement across a long sentence:</p>
      <p><u>Example 1</u>: ‘<em>The list of items that were purchased was reviewed.</em>’ </p>
      <p><u>Issue</u>: Here it's got the subject and verb confused and anchored the verb to the wrong noun (‘items’ vs ‘list’).</p>
      <p><u>Example 2</u>: ‘<em>Each of the students have submitted their assignment.</em>’</p>
      <p><u>Issue</u>: Here ‘each’ needs the singular verb ‘has’, but ‘have’ slides through instead because it agrees with the nearer plural noun ‘students’. </p>
      <h4>Tone/register mismatches</h4>
      <p><u>Example</u>: ‘<em>don't</em>’ and ‘<em>can't</em>’ in a formal document.</p>
      <p><u>Issue</u>: Casual contractions in formal writing like ‘don't’ and ‘can't’ may not be noticed. It’s not wrong grammatically but Editor's formality suggestions can be hit-or-miss at consistently flagging every instance. </p>
      <h4>Ambiguous pronoun references</h4>
      <p><u>Example</u>: ‘<em>John told Dave he was wrong.</em>’ </p>
      <p><u>Issue</u>: Grammatically perfect, but ‘he’ in that sentence is ambiguous. Who is John referring to? This is about context and needs actual comprehension. </p>
    <h2>Set custom grammar settings in Word</h2>
    <ol>
      <li><p>Go to <strong>File</strong> > <strong>Options</strong>.</p></li>
      <li>In the <em>Word Options</em> dialog select <strong>Proofing</strong>.</p>
      <p>Make sure <em>Writing Style</em> is set to <strong>Grammar & Refinements</strong>, then click on <strong>Settings</strong> next to it.</p>
      <p><img class="thumbnail border left" src="{{ '/assets/images/word/Spelling and Grammar Editor/Options Writing Style Settings.png' | url }}" alt="Options Writing Style Settings in Word" style="max-width:550px; width:100%; height:auto; vertical-align:middle"></p></li>
      <li><p>On the <em>Grammar options</em> dialog scroll and select/deselect what you need, e.g. there is a whole section of <em>Inclusiveness</em> that is turned off by default for criteria like gender bias, ethnic/racial bias, age bias, etc.</p>
      <p><img class="thumbnail border left" src="{{ '/assets/images/word/Spelling and Grammar Editor/Grammar settings.png' | url }}" alt="Grammar settings in Word" style="max-width:392px; width:100%; height:auto; vertical-align:middle"></p></li>
    </ol>

document.querySelectorAll('.rich-tooltip-trigger').forEach(trigger => {
  const id = trigger.dataset.tooltipId;
  const layer = document.getElementById('tooltip-layer');

  trigger.addEventListener('mouseenter', () => {
    if (!tooltips[id]) return;

    // clear previous
    layer.innerHTML = '';

    // build tooltip
    const wrapper = document.createElement('div');
    wrapper.innerHTML = tooltips[id];
    const tooltip = wrapper.firstElementChild;

    // position tooltip near hotspot
    const rect = trigger.getBoundingClientRect();
    tooltip.style.position = 'fixed';
    tooltip.style.top = `${rect.top + (rect.height / 2)}px`;
    tooltip.style.left = `${rect.right + 10}px`;
    tooltip.style.display = 'block';

    // rely on CSS for max-width and wrapping
    tooltip.style.maxWidth = "400px";

    // add to layer
    layer.appendChild(tooltip);

    // keep visible while hovering tooltip
    tooltip.addEventListener('mouseenter', () => {
      tooltip.classList.add('visible');
    });
    tooltip.addEventListener('mouseleave', () => {
      tooltip.remove();
    });
  });

  trigger.addEventListener('mouseleave', () => {
    const tooltip = document.querySelector('#tooltip-layer .rich-tooltip');
    if (tooltip) {
      // delay so you can move into tooltip
      setTimeout(() => {
        if (!tooltip.matches(':hover')) {
          tooltip.remove();
        }
      }, 150);
    }
  });
});
