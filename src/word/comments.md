<h1>Comments</h1>

  <section class="section-light">
  <h2>Why use comments?</h2>
  <p>Comments are a useful tool to leave notes, queries and/or feedback on a document without editing the contents of the document. Word allows multiple people to comment on the same document and each comment is tied to an author with a timestamp of when the comment was made, so it's clear who said what, and when.</p> 
  <p>Comments are normally used to collaborate with others when editing a document together or when seeking approval. Comments can be added to text and other content for others to see, reply to, and mark as 'resolved'. They let reviewers raise questions or concerns without changing the text; the author/editor editing the document directly can then decide how to edit the actual content.</p>
  <img class="thumbnail border" src="{{ '/assets/images/word/comments/New comment 3.png' | url }}" alt="New comments option via right click context menu in Word" style="max-width:766px; width:100%; height:auto; vertical-align:middle">
  
  <p>They're sometimes used alongside <a href="/word/track-changes">Track Changes</a> which is another reviewing tool in Word for collaborating with others to make propsed edits to content. This article focuses on comment themselves.</p>

  <h2>How to add a comment</h2>
  <p>Comments can be found under the Review tab on the ribbon. Select the text or content you want to leave a comment on and click <strong>New comment</strong>:</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment on ribbon.png' | url }}" alt="New comments option via right click context menu in Word" style="max-width:313px; width:100%; height:auto; vertical-align:middle">
  <p>Alternatively after selecting the text/content you can <strong>right click</strong> and select <strong>New Comment</strong> from the bottom of the <span class="glossary-hover" data-term="right-click-menu">right click menu</span> (this is faster):</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment.png' | url }}" alt="New comments option via right click context menu in Word" style="max-width:385px; width:100%; height:auto; vertical-align:middle">
  <p>A comment box will appear on the right of the page with a text box to enter in a comment.</p> 
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment 2.png' | url }}" alt="New comment added and editing in Word" style="max-width:755px; width:100%; height:auto; vertical-align:middle">
  <p>When finished typing click the <strong>arrow button</strong> and the comment will be placed like this (or if you don't need to place a comment click the &#10006; to cancel).</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment 3.png' | url }}" alt="New added comment in Word style="max-width:766px; width:100%; height:auto; vertical-align:middle">
  
  <h2>How to delete a comment</h2>
  <p>To delete a comment, click on the <strong>ellipsis (...)</strong> then from the drop down menu select <strong>Delete thread</strong>.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Delete thread.png' | url }}" alt="Delete comment thread in Word" style="max-width:423px; width:100%; height:auto; vertical-align:middle">

  <p>You can also reply to a comment and mark them as resolved which is explored in the <a href="?difficulty=intermediate">intermediate version</a> of this article.</p>

  <h2>Navigating between comments</h2>
  <p>You can move between comments made with the <strong>Previous</strong> and <strong>Next</strong> buttons on the <span class="glossary-hover" data-term="ribbon">ribbon's</span> <strong>Review</strong> tab.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Navigating comments.png' | url }}" alt="Comments in list view in Word" style="max-width:288px; width:100%; height:auto; vertical-align:middle">

  <p>Further to this there is another view setting that shows all comments in a pane so can see all comments in one place, this and other features are explored in the <a href="?difficulty=intermediate">intermediate version</a> of this article:</p>

  <p>Comments are a useful tool to attach notes, questions, or feedback to content without editing the document itself. Each comment has its author and timestamp displayed. Commenting is typically used in collaborative editing, reviews or approval workflows. They can be edited, replied to with threaded discussions, and marked as 'resolved'.</p>

  <p>They can be used alongside <a href="/word/track-changes">Track Changes</a>, another reviewing tool for multiple users to make propsed edits to content. This article focuses on comment themselves.</p>
  
  <h2 id="add">How to add a comment</h2>
  <p>While there is an option on the ribbon under Review, it's quicker to use the <span class="glossary-hover" data-term="right-click-menu">right click menu</span>. First select the content you want to add a comment to, then right click and choose <strong>New comment</strong> from the right click menu.</p> 
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment.png' | url }}" alt="New comments option via right click context menu in Word" style="max-width:385px; width:100%; height:auto; vertical-align:middle">
  <p>A comment box appears to the right of the page, enter in your comment then click the <strong>arrow button</strong> button to place the comment, or click the &#10006; to cancel.</p> 
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment 2.png' | url }}" alt="New comment added and editing in Word" style="max-width:755px; width:100%; height:auto; vertical-align:middle">
  <p>When placed it will look like this.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/New comment 3.png' | url }}" alt="New added comment in Word" style="max-width:766px; width:100%; height:auto; vertical-align:middle">

  <h2 id="delete">How to delete a comment</h2>
  <p>Comments can be deleted via <strong>ellipsis (...)</strong> > <strong>Delete thread</strong>. This will also delete any replies made underneath it.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Delete thread.png' | url }}" alt="Delete comment thread in Word" style="max-width:423px; width:100%; height:auto; vertical-align:middle">

  <h2 id="resolve">How to resolve a comment</h2>
  <p>The thumbs up on the comment box lets you marked the comment as resolved with a thumbs up icon like this below. Some users also use this function to show they agree with a comment.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Comments resolved.png' | url }}" alt="Approved comment in Word" style="max-width:303px; width:100%; height:auto; vertical-align:middle">

  <h2 id="reply">Replying to a comment</h2>
  <p>Once a comment has been created, all users will see a text field below it where you can type in a reply then select the <strong>arrow button</strong> button to insert (or click the &#10006; to cancel). Once entered the reply will be shown as a thread.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Reply thread 1.png' | url }}" alt="Typing to reply to a comment in Word" style="max-width:870px; width:100%; height:auto; vertical-align:middle">
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Reply thread 2.png' | url }}" alt="Comment replied to in Word" style="max-width:873px; width:100%; height:auto; vertical-align:middle">

  <h2 id="navigate">Navigating between comments</h2>
  <p>You can move back and forth between comments made via <strong>Previous</strong> and <strong>Next</strong> buttons on <strong>Review</strong> tab of the <span class="glossary-hover" data-term="ribbon">ribbon</span>.</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Navigating comments.png' | url }}" alt="Comments in list view in Word" style="max-width:288px; width:100%; height:auto; vertical-align:middle">

  <h2 id="views">Comment views</h2>
  <p>There are two views for comments:</p>
  <ul>
    <li><strong>Contextual</strong>: the default view as shown above with a box to the right of the page where it appears in the document.</li>
    <li><strong>List</strong>: a pane that shows all the document's comments in order. This is ueful to quickly find comments in a long document or when many comments have been added.</li>
  </ul>

  <p><em><strong>Contextual view</strong></em></p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/Contextual view.png' | url }}" alt="Comments in contextual view in Word" style="max-width:878px; width:100%; height:auto; vertical-align:middle">

  <p><em><strong>List view</strong></em></p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/List view.png' | url }}" alt="Comments in list view in Word" style="max-width:878px; width:100%; height:auto; vertical-align:middle">

  <p>In list view you can also filter comments by whether they're active or resolved or include tagging:</p>
  <img class="thumbnail border left" src="{{ '/assets/images/word/comments/List filter menu.png' | url }}" alt="Comments in list view in Word" style="max-width:320px; width:100%; height:auto; vertical-align:middle">
  
  <h2 id="pdf">Saving as a PDF with comments</h2>
  <p>When using comments there's a common trap most people fall into when saving as a PDF. By default Word will show markup like comments and track changes. If you don't want comments showing in your PDf then the markup needs to be turned off before saving as a PDF. If you don't switch this off the comments will appear on your PDF like this:</p>
  <img class="thumbnail border" src="{{ '/assets/images/word/Save as PDF/PDF with comments example.png' | url }}" alt="PDF with comments" style="max-width:789px; width:100%; height:auto; vertical-align:middle">
  <p>See this article for how to prevent them appearing in PDFs: <a href="/word/save-as-pdf/?difficulty=intermediate#pdf-comments-track-changes">Comments/track changes showing in the PDF</a>.</p>
