    Comments

    ⭐ Beginner Level

    Why use comments?

    Comments are a useful tool to leave notes, queries and/or feedback on a document without editing the contents of the document. Word allows multiple people to comment on the same document and each comment is tied to an author with a timestamp of when the comment was made, so it's clear who said what, and when.

    Comments are normally used to collaborate with others when editing a document together or when seeking approval. Comments can be added to text and other content for others to see, reply to, and mark as 'resolved'. They let reviewers raise questions or concerns without changing the text; the author/editor editing the document directly can then decide how to edit the actual content.

    They're sometimes used alongside Track Changes which is another reviewing tool in Word for collaborating with others to make proposed edits to content. This article focuses on comment themselves.

    How to add a comment

    Comments can be found under the Review tab on the ribbon. Select the text or content you want to leave a comment on and click New comment:

    Alternatively after selecting the text/content you can right click and select New Comment from the bottom of the right click menu (this is faster):

    A comment box will appear on the right of the page with a text box to enter in a comment.

    When finished typing click the arrow button and the comment will be placed like this (or if you don't need to place a comment click the ✖ to cancel).

    How to delete a comment

    To delete a comment, click on the ellipsis (...) then from the drop down menu select Delete thread.

    You can also reply to a comment and mark them as resolved which is explored in the intermediate version of this article.

    Navigating between comments

    You can move between comments made with the Previous and Next buttons on the ribbon's Review tab.

    Comments are a useful tool to attach notes, questions, or feedback to content without editing the document itself. Each comment has its author and timestamp displayed. Commenting is typically used in collaborative editing, reviews or approval workflows. They can be edited, replied to with threaded discussions, and marked as 'resolved'.

    They can be used alongside Track Changes, another reviewing tool for multiple users to make proposed edits to content. This article focuses on comment themselves.

    How to add a comment

    While there is an option on the ribbon under Review, it's quicker to use the right click menu. First select the content you want to add a comment to, then right click and choose New comment from the right click menu.

    How to delete a comment

    Comments can be deleted via ellipsis (...) > Delete thread. This will also delete any replies made underneath it.

    Replying to a comment

    Once a comment has been created, all users will see a text field below it where you can type in a reply then select the arrow button button to insert (or click the ✖ to cancel). Once entered the reply will be shown as a thread.

    Navigating between comments

    You can move back and forth between comments made via Previous and Next buttons on Review tab of the ribbon.

    Comment views

    There are two views for comments:

    • Contextual: the default view as shown above with a box to the right of the page where it appears in the document.
    • List: a pane that shows all the document's comments in order. This is useful to quickly find comments in a long document or when many comments have been added.

    Tagging and assigning in comments

    If your Word document is stored on SharePoint or OneDrive, you can tag others in a comment. You can also choose to assign a comment to someone as a task to complete.

    Note: Both tagging and assigning features require the document to be stored on SharePoint or OneDrive or these features won’t appear. SharePoint/OneDrive is what powers the modern comments/co-authoring layer in Word, Excel, and PowerPoint.

    @mention (tagging)

    Tagging a user in a comment sends a notification (email or Teams, depending on setup) to let that person know they were mentioned in a comment with a link to the document. It’s useful to draw attention to content, ask for input/advice or share ideas.

    There are several reasons you may want to tag someone in a comment thread related to a section of the document, for example:

    • Pulling in a subject matter expert
    • Redirecting a question to the right owner/department
    • Chasing an overdue query or action in the comment thread
    • Looping in a manager/superior for sign off or approval
    • Highlighting or querying further editing required
    • Flagging gaps in content

    To tag someone in a comment, type @ into the text box followed by the person’s name in the global address book associated with the SharePoint/OneDrive you’re connected to. A list of matched suggestions from that address book will pop up to choose from. Here I’ve typed 'Smith' and it’s bringing up a list of suggestions.

    Note: Remember, this feature won’t appear unless the file is stored on SharePoint or OneDrive. If it is and you don’t get the feature appearing then you need to make sure you’re connected to SharePoint or OneDrive first.

    Select the intended user from the list and they will appear as a link in the text box like this:

    Press the arrow and the tag will be placed with the message. The tagged person will now receive an automated email titled ‘[X] mentioned you in “[document]”’ with a link to the document.

    Assigning tasks in a comment thread

    Once you’ve tagged someone, an Assign to checkbox appears below the text box where you can assign the comment as an actionable task for the tagged person to complete.

    When you check the box, a small ‘Assigned to [X]’ radio button appears at the top of the comment to show it's an actionable item rather than a note. Press the arrow to execute it and it will look like this:

    The assigned person will then receive an automated email titled ‘[X] assigned you a task in “[document]”’ with a link to the document.

    When the assignee opens the document they will get a notification from the Catch up feature in the top right of the ribbon:

    At the same time the comment itself will show the task’s radio button at the top as Assigned to you.

    Once the task is complete the assignee checks the radio button and the task is marked as complete. The comment thread collapses and this ticked comment icon is left on the page:

    Clicking on the ticked comment icon will show the comment thread in the list view marked ✓ Task completed at the top, with a timestamp of when the assignee completed it in the thread.

    Saving as a PDF with comments

    There's a common trap with comments most people fall into when saving as a PDF. By default Word will show markup like comments and track changes. If you don't want comments showing in your PDF then the markup needs to be turned off before saving as a PDF. If you don't switch this off the comments will appear on your PDF like this:
